# Movie subtitles

The PC window can draw subtitles over the game's movies, from plain text files. It works for any language: the engine only needs a file of timed lines per movie.
**No subtitle text is included.** The Spanish translation keeps its subtitles as pictures without timing (they are not text), so text for Spanish, or any other language, has to be written or converted separately and put in a folder by you.

## Using a pack
1. Press SET UP ESSENTIAL MODS once so the PC window is rebuilt with the subtitle patch (`ps2run_subs_patch.py`).
2. Make a folder per language inside `C:\p3fes\subs`, for example `C:\p3fes\subs\Spanish`, and put the `.srt` files there, one per movie, named like the movie: `P3CTOP.srt`, `P3CT001_01.srt` ...
3. Settings > Language > MOVIE SUBTITLES: pick the folder. Press Play. The launcher lists where each movie lies on your disc (`movies.txt`, made once inside the pack folder) and gives the folder to the PC window.

## The .srt files
- SubRip text, UTF-8, times as `00:01:02,500 --> 00:01:05,000`. Index lines are optional; `<i>` style tags are dropped.
- Time zero is the start of the movie. Check a file with `python3 p3fes_subs.py check P3CTOP.srt`.
- Letters: Latin with accents, Greek and Cyrillic. Chinese, Japanese and Korean letters are not in the built-in font yet and show as `?`.
- `python3 p3fes_subs.py movies "game.iso" -o FOLDER` lists the 41 movies of the disc with their names (and writes `movies.txt`).

## Making the text with speech recognition
`p3fes_subs.py transcribe` listens to the movies on your own disc and writes a timed `.srt` for each (English by default, `--lang ja` for the Japanese dub). It uses faster-whisper, which runs on your computer and downloads its speech model once (the small model is about 500 MB).
1. `pip install --break-system-packages faster-whisper imageio-ffmpeg` (Ubuntu side; skip `--break-system-packages` if pip refuses it)
2. Try one movie: `python3 tools/p3fes_subs.py transcribe "/mnt/c/p3fes/<your disc>.iso" -o /mnt/c/p3fes/subs/English --only P3CTOP`
3. Then all of them (it skips movies that already have a file): the same command without `--only`.
After it finishes run `python3 tools/p3fes_subs.py polish FOLDER`: it joins lines that stopped mid-sentence, drops sign-offs the recogniser invents on music ("Thank you for watching"), fixes the usual name slips and sets the two-row layout (the untouched files are kept in `FOLDER/raw`). Speech recognition cannot sing, so movies that are mostly music (the title song, the staff roll) come out empty or wrong and should be left empty.
For the best result use `--model medium --novad` (about 1.5 GB, slow on a CPU: the 41 movies took a long while). The small model misses short lines; `--novad` stops the speech detector from cutting them out, but the recogniser then also invents text on music, so remove those lines by hand ("Thank you for watching", credits, web addresses) and leave the song and staff-roll movies empty.
The result is a starting point: speech recognition mistakes names and short lines, so read the files and fix them. A translation can then be made from the English file line by line, keeping the same times.

## Timing
The window starts the clock when the game first reads a movie from the disc. The picture appears a little later than that, so lines can come early or late. While a movie plays press `]` (subtitles later) or `[` (earlier) in the game window, 0.25 s a press; the console prints the delay. To keep the value, set `PS2_SUBS_DELAY=-0.5` (seconds) in `~/.p3fes-window-env`. A movie that is skipped and started again restarts the clock.

## How it works
- `runtime/src/disc.cpp`: every disc read is checked against the sector ranges in `movies.txt` (`PS2_SUBS` folder); a hit tells `system.cpp` the movie name and the frame it started.
- `host/subs.inc` (included by `window.cpp`): once a frame it takes the time since the start (59.94 frames a second plus the delay), finds the line, draws it on the CPU (white letters, dark outline, centred, wrapped to 84 % of the width) and shows it in a small borderless always-on-top window over the bottom of the game window. On Windows the window is see-through and ignores the mouse and keyboard (a layered window); elsewhere it is a dark box.
- `host/subs_font.inc`: DejaVu Sans Bold, 30 px, 449 glyphs, 4-bit alpha, base64 (Bitstream Vera licence: free to use and share; the font is generated by `tools/gen_subs_font.py`).
- It is a second window, so it works whichever way the game picture is drawn. Nothing about the game changes.

## Known limits
- Untested in the game so far (compiled and the drawing checked on this computer only).
- Exclusive fullscreen would hide the subtitle window; borderless/windowed fullscreen (F11) is fine.
- Two movies share the name P3CT003 (the sound folder copy); both are listed and both show the same subtitle file.
